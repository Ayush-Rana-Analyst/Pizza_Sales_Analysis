 Pizza Sales Analysis (SQL)

 📌 Overview
This repository contains three CSV datasets related to pizza sales.  
The goal of this project is to practice and showcase **SQL queries** for business insights.

 📂 Dataset Information
- **Pizzas.csv** → Pizza types, sizes, and prices  
- **Orders.csv** → Customer orders with timestamps  
- **OrderDetails.csv** → Line‑items linking orders to pizzas  

 🎯 Project Scope
- Practicing SQL queries such as:
  - Filtering and sorting data  
  - Aggregations (SUM, AVG, COUNT)  
  - Grouping by pizza type, size, or order date  
  - Sales trend analysis and revenue insights  

 🛠️ Tools Used
- SQL (MySQL / PostgreSQL / SQLite)  
- Datasets: `Pizzas.csv`, `Orders.csv`, `OrderDetails.csv`  

 📊 Example Queries
- Find total revenue by pizza category  
- Identify the most popular pizza size  
- Calculate daily/weekly sales trends  
- Top 5 best‑selling pizzas  

 🚀 How to Use
1. Import all CSV files into your SQL database.  
2. Run queries from the `queries.sql` file (to be added).  
3. Explore results for insights into pizza sales and pricing.  

 📈 Purpose
This project is part of my **data analytics portfolio**, focusing on SQL query solving and business insights using structured datasets.
